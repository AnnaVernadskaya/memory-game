# memory-game# Memory Game — Find a Pair

Игра на поиск пар с акварельными котятами.

## Правила игры

На поле расположены 16 карточек — 8 пар. Открывайте по две карточки и находите одинаковые изображения.

- Совпавшие карточки остаются открытыми.
- Несовпавшие закрываются через одну секунду.
- Один ход — открытие двух разных доступных карточек.
- Цель — найти все пары за минимальное количество ходов.

## Реализовано

- Генерация всей разметки через JavaScript.
- Перемешивание карточек алгоритмом Фишера — Йейтса.
- Подсчёт ходов и найденных пар.
- Защита от повторных кликов и выбора третьей карточки.
- Модальное окно победы с итоговым количеством ходов.
- Перезапуск игры без перезагрузки страницы.
- Адаптивное оформление.

## Технологии

HTML, CSS, JavaScript, ES Modules.

## Локальный запуск

1. Клонируйте репозиторий:

   git clone https://github.com/AnnaVernadskaya/memory-game.git

2. Перейдите в папку проекта:

   cd memory-game

3. Переключитесь на ветку приложения:

   git switch memory-game

4. Откройте папку проекта в VS Code.
5. Установите расширение Live Server, если оно ещё не установлено.
6. Нажмите правой кнопкой мыши на index.html и выберите Open with Live Server.

Приложение откроется в браузере. Установка npm-зависимостей не требуется.

Запускайте проект через локальный сервер: открытие index.html напрямую.
